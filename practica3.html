📝 Comandos GitHub

Comandos GitHub

Definir lo que hacen los siguientes comandos:

git status

git init

git add .

Agrega todos los archivos modificados y nuevos del directorio actual al área de preparación (staging area). El punto "." indica "todos los archivos". Sirve para preparar múltiples archivos para el commit.

git add ruta_del_archivo

Agrega un archivo específico al área de preparación (staging area). Se usa cuando solo quieres preparar un archivo en particular para el próximo commit, en lugar de todos. Debes reemplazar ruta_del_archivo por la ruta real, por ejemplo: git add carpeta/archivo.txt.

git restore .

Restaura todos los archivos del directorio actual a su último estado confirmado (último commit). Deshace todos los cambios no guardados sin afectar commits anteriores.

git restore ruta_del_archivo

Restaura únicamente el archivo indicado a su versión del último commit. Es útil cuando quieres deshacer cambios solo en un archivo específico sin afectar el resto.

git restore .

git restore ruta_del_archivo

git reset --soft HEAD~1

git restore --staged .

git clean -f

git merge --abort
